# Lógica de Programação com Python

Este repositório reúne meus estudos e exercícios práticos do curso de lógica de programação da Rocket. O objetivo é aprender os fundamentos da linguagem Python por meio de pequenos programas e desafios do dia a dia.

## Conteúdos estudados

- Tipos de dados e variáveis
- Entrada e saída de dados
- Operadores matemáticos e lógicos
- Estruturas condicionais (`if`, `elif` e `else`)
- Estrutura `match case`
- Exercícios de fixação e pequenos projetos

## Organização do repositório

### `Estudos com Python`

Contém os exemplos desenvolvidos durante as aulas, com foco nos conceitos básicos da linguagem e nas estruturas de controle.

### `Praticando`

Contém exercícios para praticar os conceitos estudados, como calculadora, média de notas, desconto de preço, semáforo, maioridade e número secreto.

## Como executar os exercícios

É necessário ter o Python instalado. Depois, abra um terminal na pasta do repositório e execute o arquivo desejado:

```bash
python "Praticando/CalcSimples.py"
```

Os programas são interativos e podem solicitar informações pelo terminal.
